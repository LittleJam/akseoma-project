# Приложение для iPhone

Surf the Task теперь не только сайт, но и настоящее приложение для iOS.
Внутри — тот же React и та же сборка Vite; снаружи — нативная оболочка
(Capacitor), которая показывает их в WKWebView и даёт доступ к системным
возможностям. Одна кодовая база, две витрины: сайт на GitHub Pages и
приложение на телефоне.

## Что понадобится один раз

| | |
|---|---|
| **Xcode** | из App Store. Сейчас в системе стоят только Command Line Tools — их не хватит: нужен полный Xcode, чтобы собрать и подписать приложение. После установки: `sudo xcode-select -s /Applications/Xcode.app` |
| **Apple ID** | обычный, бесплатный. Для установки на свой телефон платный аккаунт разработчика не нужен |
| **CocoaPods** | **не нужен.** Capacitor 8 собирает зависимости через Swift Package Manager |

## Сборка и запуск

```bash
npm run ios:sync     # собрать веб в нативном режиме и переложить в проект Xcode
npm run ios:open     # открыть проект в Xcode
```

Дальше в Xcode:

1. Выбрать проект **App** в списке слева → вкладка **Signing & Capabilities**.
2. В поле **Team** выбрать свой Apple ID (`Add an Account…`, если его там ещё нет).
3. Если Xcode ругается на идентификатор — поменять **Bundle Identifier** на свой,
   например `com.вашеимя.surfthetask`. Тот же идентификатор стоит вписать в
   `capacitor.config.json` (`appId`), чтобы `cap sync` его не перетирал.
4. Подключить iPhone кабелем, выбрать его в списке устройств сверху и нажать ▶.
5. На телефоне: **Настройки → Основные → VPN и управление устройством** →
   доверять своему сертификату разработчика. Без этого приложение не запустится.

После любых правок в коде — снова `npm run ios:sync` и ▶ в Xcode. Пересобирать
сам проект Xcode не нужно, меняется только содержимое `ios/App/App/public`.

### Сроки жизни сборки

С бесплатным Apple ID подпись действует **7 дней**: через неделю приложение
перестанет открываться, и его надо переустановить тем же ▶. Чтобы этого не
делать, нужен платный Apple Developer Program ($99 в год) — с ним подпись живёт
год, а приложение можно раздать через TestFlight.

## Что внутри устроено иначе, чем на сайте

Оболочка не переписывает приложение, но три места знают, где они запущены —
каждое помечено проверкой `Capacitor.isNativePlatform()`:

- **Напоминания** ([src/utils/reminders.js](../src/utils/reminders.js)) — на сайте
  это таймеры, которые работают, только пока вкладка открыта. В приложении
  напоминания отдаются системе на неделю вперёд, и iOS будит их сама: телефон
  напомнит о задаче, даже если приложение закрыто. Это главная причина, ради
  которой стоило делать нативную оболочку.
- **Выгрузка недели в календарь** ([src/utils/ics.js](../src/utils/ics.js)) —
  WKWebView не умеет скачивать файлы, поэтому `.ics` пишется во временную папку
  приложения и отдаётся системному «Поделиться»; оттуда iOS сама предлагает
  «Добавить в Календарь».
- **Строка состояния** ([src/utils/native.js](../src/utils/native.js)) — цвет из
  `<meta name="theme-color">` внутри приложения не действует, стиль часов и
  значков просит у системы отдельный вызов.

Кроме того, в нативной сборке **нет сервис-воркера**: файлы и так лежат внутри
приложения, а кеш поверх них означал бы только шанс показать старую сборку после
обновления. Сборка для этого отдельная — `npm run build:native`: у сайта пути
ведут в подпапку GitHub Pages, а внутри приложения страница живёт в корне.

Что на iOS не работает и не будет: **автосохранение в файл** (File System Access
API есть только в десктопных браузерах). Облачная синхронизация, заметки,
расписание, темы, ввоз календаря — всё на месте.

## Android

Отдельной работы почти не требует: `npx cap add android`, и та же сборка
поедет в Android Studio. Нативные ветки в коде писались сразу для обеих систем.

## Где что лежит

```
capacitor.config.json   идентификатор, имя, папка сборки
ios/App/                проект Xcode (коммитится: в нём настройки подписи и иконки)
ios/App/App/public/     сюда cap sync кладёт собранный веб (в git не попадает)
ios/App/App/Assets.xcassets/  иконка приложения и заставка
```

Иконка и заставка собраны из тех же исходников, что и значок сайта:

```bash
rsvg-convert -w 1024 -h 1024 public/icon-maskable.svg \
  -o ios/App/App/Assets.xcassets/AppIcon.appiconset/AppIcon-512@2x.png
```
