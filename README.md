# Personal Jira - Персональный менеджер задач

Упрощённая версия Jira для управления задачами в виде канбан доски.

## ✨ Возможности

✅ **Канбан доска** с тремя колонками (К сделать, В процессе, Готово)  
✅ **Управление проектами** - создай несколько проектов, каждый со своей доской  
✅ **Редактирование задач** - название, описание, приоритет  
✅ **Загрузка изображений** - добавляй картинки в задачи  
✅ **История изменений** - вся история изменений сохраняется в памяти  
✅ **Темная тема** - переключение между светлой и тёмной темой  
✅ **Локальное сохранение** - все данные сохраняются в браузере (localStorage)  

## 🚀 Как запустить

### 1. Установи зависимости
```bash
npm install
```

### 2. Запусти проект в режиме разработки
```bash
npm run dev
```

Проект откроется на `http://localhost:5173`

## 📦 Сборка для продакшена
```bash
npm run build
```

## 🎯 Как использовать

1. **Создай проект** - нажми "+" в левой панели и введи название
2. **Добавь задачу** - напиши название и выбери колонку
3. **Отредактируй задачу** - кликни на задачу, чтобы открыть редактор
4. **Добавь изображение** - в редакторе есть раздел для загрузки картинок
5. **Посмотри историю** - вся история изменений доступна в редакторе
6. **Переключи тему** - нажми на иконку луны/солнца в левом углу

## 🛠️ Технологический стек

- **React 18** - библиотека для UI
- **Vite** - быстрый build tool
- **Tailwind CSS** - утилиты для стилизации
- **Lucide React** - иконки
- **localStorage** - сохранение данных в браузере

## 📝 Требования

- Node.js 16+
- npm или yarn

## 💡 Советы

- Все данные сохраняются локально в браузере
- Можешь использовать сразу несколько проектов
- История изменений помогает отслеживать все правки
- Тёмная тема удобна для вечерней работы

Приятного использования! 🎉
